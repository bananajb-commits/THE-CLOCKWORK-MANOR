# The Clockwork Manor — Official Companion Hub

Companion site and free printable 4×4 blank logic grids for **The Clockwork Manor: 75 Multi-Stage Mystery Logic Puzzles (Vol. 1)** by **Arthur Bramwell** (Clockwork Mystery Press).

## Files
- `index.html` — Landing page & download hub
- `clockwork_free_blank_grids.pdf` — Printable US Letter 2-page blank 4×4 logic grid sheet (Standard & 1-Lie Check modes)
- `wrangler.jsonc` / `.assetsignore` — Cloudflare Workers static asset configuration
